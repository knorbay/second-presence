# Game-native branding

The menu scene is drawn live by `menu_scene.py` using the actual ship renderer, wall-blocked flashlight, crew sprite and creature renderer. It uses an independent map and does not advance or change the campaign.

`cover.png` is a 1600×900 export of this scene with the live wordmark. `emblem.svg` and transparent `emblem.png` are the two-hatch geometric mark drawn by `draw_ship_mark`. The menu draws this mark directly and does not load the PNGs.

The earlier generated illustration and ornate badge were replaced following the user's feedback. They remain in the backup archive made before this edit.
