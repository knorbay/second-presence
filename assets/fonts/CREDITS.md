# UI fonts

Barlow Semi Condensed Regular and SemiBold. Copyright 2017 The Barlow Project Authors (https://github.com/jpt/barlow). Unmodified fonts bundled under the SIL Open Font License 1.1; see OFL.txt.

Official distribution: https://github.com/google/fonts/tree/main/ofl/barlowsemicondensed

These files are loaded explicitly by ui_fonts.py. No installed system font is required. All displayed Turkish letters, punctuation and UI characters were checked against the font cmap. Unsupported direction arrows are represented by text/key names and supported separators; task checkmarks are drawn as lines.
